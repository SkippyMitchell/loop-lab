# Loop Lab

A blind-accessible looping and sampling web app. Open `index.html` (or the GitHub Pages site) in Safari.

Speech uses eSpeak via [speak.js](https://github.com/kripken/speak.js) (`speakGenerator.js`, `espeak-worker.js`),
which is licensed under the GNU GPL v3 — see `espeak-LICENSE.txt`. The voice variant files from eSpeak's
`voices/!v` folder were added to `speakGenerator.js`.
